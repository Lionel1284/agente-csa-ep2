# Datos del prototipo

Todos los datos de esta carpeta son **simulados o extractos resumidos con fines académicos**.

- `corpus_simulado.json`: 6 procedimientos internos ficticios y 2 fuentes externas públicas resumidas.
- `operativos_iniciales.json`: estado inicial de tres operativos ficticios usados en los escenarios de prueba.

No se incluyen datos clínicos, personales ni información confidencial real de CSA Salud Integral SpA.
