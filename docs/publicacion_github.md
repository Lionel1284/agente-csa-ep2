# Publicación en GitHub

Se recomienda crear el repositorio como **privado** mientras se encuentre en evaluación.

Nombre sugerido:

`agente-csa-ep2`

Después de crear un repositorio vacío en GitHub:

```bash
git init
git add .
git commit -m "feat: entrega final agente CSA EP2"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/agente-csa-ep2.git
git push -u origin main
```

No marques la opción de crear README, `.gitignore` o licencia al crear el repositorio remoto,
porque estos archivos ya están incluidos en esta carpeta.
